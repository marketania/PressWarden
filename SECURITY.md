# Security policy

## Reporting a vulnerability

Please do not publish an exploit, credential exposure, or customer-sensitive security issue in a public issue. Prefer GitHub's private vulnerability reporting / security advisory flow for this repository. If that is unavailable, contact the maintainers through [Marketania.com](https://marketania.com/) and reference `PressWarden security report`.

Include the affected version, environment, reproduction steps, impact, and any proposed fix. Do not include live third-party credentials or customer data.

## Scanner safety

PressWarden is an administrative security tool. Remediation is interactive by default and quarantine-backed. Users should maintain independent backups and review findings before changing production systems.

PressWarden is developed and maintained with support from [Marketania](https://marketania.com/), a digital services and WordPress-focused agency.
