# PressWarden 2.0.0

WordPress security, malware detection and investigation.

## Breaking migration from the combined 1.x tool

PressWarden is now security-only. `full`, `db`, `fast`, and `incident` no longer perform routine database cleanup/optimization or set hardening policies. Explicit security remediation remains separately authorized. Existing evidence and reports are preserved; start a fresh security scan rather than resuming a mixed 1.x run.

- `presswarden lock/unlock/wp-settings/auto-updates ...` moved to **PressHarden**.
- `presswarden litespeed/litespeed-db/cleanup ...` moved to **PressGarden**.
- Former commands give migration guidance and exit 2; they never silently launch a sibling.

Install the replacement tools and review cron jobs before updating production installations. The repositories are independent; no fourth runtime repository is needed.

## Primary commands

```bash
presswarden fast example.com
presswarden full example.com
presswarden incident example.com
presswarden inspect db example.com
```

## Verification and downloads

This release is published only after all required main-branch workflows pass for the exact source commit. `SOURCE.json` records the commit, Git tree and passing workflow-run links. `SHA256SUMS` covers the tracked-source archive, source manifest and these notes. No local work files, credentials or client data are included.

The initial split included isolated WordPress/MySQL integration, PHP 7.4 compatibility, fixture/lifecycle tests and downloaded-installer regressions. Consult the recorded CI evidence for the released commit rather than assuming all hosting environments were tested.

Publication does not install anything on client servers or modify websites, databases or scheduled tasks. Effective web PHP settings, actual HTTP cache/CDN behavior, credentialed external services and a database restore/recovery drill remain staging checks. A checksum-verified backup is not a tested restore.

See `docs/MIGRATION.md`, `docs/RELEASING.md` and `PROVENANCE.md` in the source archive.
